## Deploy with GitHub Pages

1. Create a GitHub repository named `jay-sorathiya.github.io` if that username is available.
2. Upload the contents of this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will publish the site at your GitHub Pages URL.

## Before publishing

Replace:
- `YOUR-GITHUB-USERNAME` in `index.html`
- `YOUR_EMAIL@example.com` in `index.html`
- `assets/resume.pdf` with your real resume PDF
- project links as your Risk Lab projects become real
- placeholder project text only after the underlying project exists
